# Leetcode Practice Repository

This repository is a consolidated collection of algorithm and data-structure practice focused on:

- Searching Operations
- Sorting Operations
- Array Problems
- Two-Pointer Technique

It brings together Python and C++ implementations used for learning and interview preparation.

## Topics Covered

### 1. Searching Operations
Includes core searching algorithms such as:

- Binary Search
- Lower Bound
- Upper Bound
- Search in Rotated Sorted Array
- Binary Search on answer pattern (like minimum eating speed)

### 2. Sorting Operations
Includes common sorting algorithms such as:

- Bubble Sort
- Merge Sort
- Quick Sort
- Heap Sort

### 3. Array
Includes simple array-focused concepts and operations:

- Basic array understanding
- Linear search
- Array manipulation patterns

### 4. Two Pointer Technique
Includes problems solved using the classic two-pointer method:

- Two Sum in a sorted array
- Pointer-based optimization strategies

## How to Use

Open the relevant folder and run the code files directly.

Examples:

```bash
python Searching-Operations/binary_search.py
```

Or for C++ files:

```bash
g++ -std=c++17 Searching-Operations/search_rotated_sorted_array.cpp -o rotated
./rotated
```
